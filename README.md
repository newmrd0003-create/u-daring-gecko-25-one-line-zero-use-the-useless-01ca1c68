Entry for the [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) on make.fun: one original line, at most 200 characters, describing a hilariously useless superpower.

## The line

> My superpower is joining any queue and instantly making it the slowest one in the building — I was chosen, and it was clearly a clerical error.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), asserting it stays within the 1–200 character gate. No network, no dependencies, no secrets — just Python 3 and one joke.

Run it:

```sh
python3 main.py
```
